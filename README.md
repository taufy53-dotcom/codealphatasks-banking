# 🏦 Banking System (C++ / Xcode)

This is a simple **Banking System project** built using **C++** and developed in **Xcode**.  
It demonstrates fundamental programming concepts such as file handling, classes, and basic banking operations like account creation, deposits, withdrawals, and balance inquiries.

---

## 🚀 Features
- Create a new account  
- Deposit and withdraw money  
- Check account balance  
- Modify and delete accounts  
- Simple file-based data storage
